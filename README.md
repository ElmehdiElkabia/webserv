# Webserv 🌐

A custom HTTP server implemented in C++98 as part of the 42 / 1337 curriculum.

## About

Webserv explores how web servers work internally by implementing socket communication, HTTP request/response handling, configuration parsing, client connections, and server-side request processing.

## Concepts

- TCP sockets
- HTTP/1.1
- Request and response parsing
- Non-blocking I/O
- Client/server architecture
- Configuration parsing
- Multiple client connections
- CGI and static content handling

## Topics

`cpp` `c++98` `http` `http-server` `sockets` `networking` `tcp-ip` `linux` `42-school` `1337`

## Build

```bash
make
```

## Run

```bash
./webserv config/default.conf
```
